"""bounty_watch_report.py — markdown bounty-watch report generator.

The module renders a deterministic, human readable markdown report out of
already-collected bounty-watch data (per-program JavaScript bundle drift and
programs that resumed after a pause).

It can be used either as an importable library or as a CLI::

    python bounty_watch_report.py --output report.md --log-level DEBUG

Design goals
------------
* **Zero hidden state** — every model is an immutable, validated dataclass.
* **Fail fast, fail loud** — all user supplied text is validated before it
  ever reaches the markdown output (control characters and backticks are
  rejected to prevent markdown/terminal injection).
* **Predictable logging** — configuration happens exactly once, is
  idempotent and is overridable through ``BOUNTY_WATCH_LOG_LEVEL``.
* **Linear rendering** — sections are rendered into lists and joined once,
  keeping the whole pipeline O(n) in the number of entries.
"""
